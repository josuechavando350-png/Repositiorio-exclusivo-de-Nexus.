# Nexus Bot Studio · sitio principal

Sitio estático de nexusbotstudio.com: agencia de marketing digital y páginas web en la Ciudad de México.

- `index.html`: página principal (HTML, CSS y JS en un solo archivo, sin dependencias).
- `aviso-de-privacidad.html`: aviso de privacidad integral (LFPDPPP).
- `vercel.json`: URLs limpias y cabeceras de seguridad.
- Imágenes: `hero.jpg`, `letters.png` (máscara del destello), `og.jpg` (vista previa al compartir), íconos.

Se despliega en Vercel como sitio estático, sin paso de build.
